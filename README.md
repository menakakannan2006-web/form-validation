# form-validation
 #Form Validation Project:
 #About the Project:
This project is a responsive Form Validation application developed using HTML, CSS, and JavaScript. It validates user input and ensures that the entered details meet the required conditions before submitting the form.
#Technologies Used:
HTML5 – Structure of the form.
CSS3 – Styling and responsive design.
JavaScript – Form validation and error handling.
 #Features:
User-friendly form interface.
Input field validation.
Required field checking.
Email format validation.
Password validation.
Error messages for invalid inputs.
Successful form submission message.
